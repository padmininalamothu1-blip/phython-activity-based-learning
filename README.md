# Python Case Study Solutions

## Introduction
This project contains 10 Python programs designed to solve real-world problems using basic programming concepts.

## Case Studies
1. **University Scholarship Allocation:** Checks student eligibility and ranks applicants.
2. **Progressive Electricity Billing:** Calculates electricity bills based on consumption.
3. **Hospital Billing:** Calculates patient charges, concessions, and pending payments.
4. **Employee Payroll:** Calculates salaries, deductions, and net pay.
5. **Telecommunications Cost Optimization:** Compares mobile plans and selects the cheapest suitable plan.
6. **Railway Fare Calculator:** Calculates ticket fares, concessions, and cancellation refunds.
7. **Retail Billing:** Calculates product prices, taxes, and discounts.
8. **Manufacturing Cost Analysis:** Calculates production costs, revenue, and profit.
9. **Travel Budget Analysis:** Converts currencies and tracks travel expenses.
10. **Campus Event Financial Planning:** Calculates event expenses, sponsorship, and break-even registrations.

## Technologies Used
- Python
- Basic input and output
- Variables and data types
- Operators and conditional statements
- Loops and strings
- Lists and tuples
- Basic algorithms and problem-solving

## How to Run
1. Install Python on your computer.
2. Open a Python editor, such as IDLE or VS Code.
3. Copy the required program into a Python file.
4. Save the file with a `.py` extension.
5. Run the program and enter the requested inputs.

## Conclusion
These case studies help develop logical thinking, problem-solving skills, and practical knowledge of Python programming.
